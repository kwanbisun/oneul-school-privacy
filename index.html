백업은 이용자가 직접 실행하며 Android 파일 선택기에서 지정한 위치에 학기·수업·과제·폴더 연결 정보, 개인 일정과 가져오기 중복 방지 식별값, 일정 프리셋 및 알림·자동 정리 설정을 JSON 파일로 저장합니다. 백업 파일은 앱에서 별도로 암호화하지 않습니다. 개인 일정과 메모가 포함되므로 안전한 위치에 보관하고 타인에게 전달할 때 포함된 내용을 확인해 주세요.

클라우드 저장 위치를 선택하면 해당 문서 제공자가 파일을 전송·동기화할 수 있습니다. 이는 이용자가 선택한 서비스의 기능이며 캘린더투유가 자체 서버로 자동 업로드하는 기능은 아닙니다. 실제 자료 파일과 Android 권한은 백업에 포함되지 않습니다. 복원은 미리보기와 확인 후 기존 데이터를 덮어쓰지 않고 별도 학기로 추가합니다. 앱의 Android 자동 백업과 기기 이전은 배포 설정에서 제외합니다.
