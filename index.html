1. 적용 범위와 기본 원칙

관비선은 캘린더투유 Android 앱에서 처리하는 정보와 이용자의 선택을 이 방침으로 안내합니다. 캘린더투유(이전 이름: 오늘학교)는 회원가입 없이 개인 일정, 주간 일정, 할 일과 자료 폴더를 관리하는 앱입니다. 운영자가 수업·과제 데이터를 받는 자체 서버, 광고 기능 또는 별도의 이용 분석 서비스를 운영하지 않습니다.

2. 기기에서 처리하는 정보와 목적

학기 이름·기간·시간대, 과목명·교수명·강의실·수업 시간·메모, 과제명·메모·중요도·예상 소요 시간·진행률·마감·완료 시각을 앱 내부 데이터베이스에 저장합니다. 시간표와 Today 표시, 과제 관리, 알림 및 위젯 제공에 사용합니다. 강의실은 이용자가 입력한 수업 장소이며 기기의 위치를 추적하여 얻지 않습니다.

월별 캘린더·위젯 표시 설정, 알림 날짜·시각, 완료 과제 정리 설정과 알림 중복 발송 방지를 위한 기록 등은 기기에 저장합니다. 알림과 홈 화면 위젯에는 수업·과제 정보가 표시될 수 있습니다. 잠금 화면 알림 공개 범위는 Android 설정에서, 위젯 표시는 홈 화면에서 관리할 수 있습니다.

3. 시간표 이미지 인식

이용자가 Android 사진 선택기에서 고른 이미지만 읽습니다. 이미지와 인식 결과는 Google ML Kit의 앱에 포함된 한국어 인식 모델로 기기 안에서 처리합니다. 앱은 원본 이미지를 별도 파일로 복사하여 보관하지 않습니다. 검토 중인 항목과 선택한 이미지 주소는 화면 복구를 위한 임시 상태로 남을 수 있으며, 이용자가 확인하여 저장한 수업 정보는 앱 내부 데이터베이스에 보관합니다.

ML Kit는 일반적으로 기기·앱 정보, 설치별 식별자, 처리 성능·사용 이벤트 등의 진단 정보를 다루는 SDK입니다. 캘린더투유는 ML Kit 진단 전송용 구성요소를 제거하고 로컬 이미지 인식에 사용합니다. 0.50.0 이전 배포 구성에서는 인터넷 통신 권한도 제거했습니다. 공휴일 자동 갱신을 제공하는 0.50.0부터 인터넷 권한을 사용하지만, 플랫폼 HTTPS 통신의 신뢰 대상을 공휴일 자료 호스트로 제한하고 ML Kit 진단 전송용 구성요소 제거를 유지합니다. 사진이나 인식한 수업 내용을 운영자의 서버로 업로드하지 않습니다.

휴대폰 캘린더 가져오기

이용자가 가져오기를 실행하고 캘린더 읽기 권한을 허용하면 기기에 공개된 캘린더 이름·계정 표시 정보와 선택한 기간의 일정 제목·시간·시간대·종일 여부·장소·메모·색상을 읽어 미리보기로 표시합니다. 선택하여 가져온 일정과 중복 방지용 원본 식별값의 해시만 앱 내부 데이터베이스에 저장하며, 계정 표시 정보는 저장하지 않습니다. 반복 일정은 선택 기간의 개별 일정으로 복사됩니다. 원본 수정·삭제 또는 자동 동기화는 하지 않으며 서버로 전송하지 않습니다. 권한을 거부해도 다른 기능은 사용할 수 있습니다. 권한 해제는 이후 읽기를 차단하며 이미 복사한 일정은 앱에서 별도로 삭제할 수 있습니다. 복사본 삭제는 원본에 영향을 주지 않습니다.

공휴일 자료 자동 갱신 (0.50.0부터)

자동 갱신은 기본적으로 꺼져 있으며 설정에서 선택하여 켤 수 있습니다. 앱은 마지막 성공한 갱신 후 7일 이상 지났고 인터넷 연결과 배터리 80% 이상 조건을 충족할 때 GitHub Pages의 공개 공휴일 파일을 HTTPS로 내려받습니다. Android의 백그라운드 실행 정책에 따라 실제 실행은 늦어질 수 있습니다. 갱신 실패 시 기존 자료를 유지합니다. 배터리 잔량과 마지막 갱신 시각은 기기에서만 확인합니다.

다운로드 과정에서 호스팅 제공자 GitHub에 IP 주소, 요청한 공개 파일 경로, 접속 시각 및 모든 앱에 공통인 요청 프로그램 이름 등 통신에 필요한 접속 정보가 전달됩니다. GitHub는 서비스 제공·보안 등의 목적으로 접속 정보를 처리할 수 있으며, 보관과 삭제는 GitHub의 정책에 따릅니다. 운영자는 개별 이용자의 다운로드 접속 로그를 제공받지 않습니다. 일정·할 일·메모·사진·연락처·기기 위치·배터리 잔량·설치별 식별자를 이 요청에 넣지 않습니다. 로그인, 광고, 이용자별 추적 또는 맞춤형 광고에 사용하지 않습니다.

공휴일 공식 자료 조회용 인증키는 게시 서버의 비밀 저장소에서만 사용하며 앱이나 공개 파일에 포함하지 않습니다. 자동 갱신을 끄면 예약된 작업을 취소하고 진행 중인 요청에 중단을 요청합니다. 이미 내려받은 공개 공휴일 자료는 오프라인 사용을 위해 기기에 남으며 앱 저장공간 삭제 또는 앱 제거 시 삭제됩니다. 자동 갱신을 켜지 않아도 일정 관리 등 기본 기능은 사용할 수 있습니다.

4. 자료 폴더와 외부 앱

선택한 자료 폴더의 이름과 연결 주소(URI)를 저장하고 Android가 허용한 범위의 읽기 권한을 사용합니다. 캘린더투유는 연결된 실제 자료 파일을 복사·수정·삭제하지 않습니다. 이용자가 자료 파일을 열면 해당 파일을 여는 외부 앱에 파일 주소와 읽기 권한을 전달합니다. 폴더 연결을 해제해도 실제 자료 파일은 남습니다. 클라우드 문서 제공자나 외부 뷰어의 처리는 해당 서비스의 방침에 따릅니다.

5. 수동 백업과 복원

백업은 이용자가 직접 실행하며 Android 파일 선택기에서 지정한 위치에 학기·수업·과제·폴더 연결 정보, 개인 일정과 가져오기 중복 방지 식별값, 일정 프리셋 및 알림·자동 정리 설정을 JSON 파일로 저장합니다. 백업 파일은 앱에서 별도로 암호화하지 않습니다. 안전한 위치에 보관하고 타인에게 전달할 때 포함된 내용을 확인해 주세요.

클라우드 저장 위치를 선택하면 해당 문서 제공자가 파일을 전송·동기화할 수 있습니다. 이는 이용자가 선택한 서비스의 기능이며 캘린더투유가 자체 서버로 자동 업로드하는 기능은 아닙니다. 실제 자료 파일과 Android 권한은 백업에 포함되지 않습니다. 복원은 미리보기와 확인 후 기존 데이터를 덮어쓰지 않고 별도 학기로 추가합니다. 앱의 Android 자동 백업과 기기 이전은 배포 설정에서 제외합니다.

6. 권한과 선택

알림 권한은 일정·할 일 알림에, 정확한 시간 허용은 일정 알림과 알람의 시간 정확도에 사용합니다. 일정별 알람은 이용자가 선택한 경우에만 예약 시각에 소리·진동과 알람 알림을 제공합니다. 소리를 재생하는 동안 Android의 포그라운드 서비스를 사용하며, 이용자가 끄거나 미루거나 최대 10분이 지나면 재생을 중단합니다. 알람 설정과 중복 방지·미루기 기록은 기기에 저장하며 서버로 전송하지 않습니다. 권한을 거부해도 일정·할 일 관리 기능을 사용할 수 있으며, 알림이 표시되지 않거나 늦어지고 알람이 울리지 않을 수 있습니다. 사진과 폴더는 시스템 선택기로 지정한 범위에 접근합니다. 카메라·마이크·연락처·기기 위치나 사진 보관함 전체 접근 권한을 요청하지 않습니다.

7. 보관과 삭제

기기에 저장된 수업·과제는 이용자가 앱에서 수정하거나 삭제할 수 있습니다. 완료 과제 자동 정리가 켜져 있으면 완료 후 72시간이 지난 과제가 정리 대상이 되며, 기기 상태에 따라 실제 삭제는 늦어질 수 있습니다. 처음 켜거나 다시 켠 경우 및 백업 복원 시에는 최소 72시간의 보관 유예가 적용됩니다. 자동 정리는 설정에서 끌 수 있습니다.

Android의 앱 저장공간 삭제 또는 앱 제거로 앱 내부 데이터를 삭제할 수 있습니다. 다만 직접 내보낸 백업, 원본 사진, 자료 폴더 및 외부 서비스에 남은 사본은 삭제되지 않으므로 해당 저장 위치에서 별도로 관리해야 합니다. 운영자는 기기 안의 데이터를 원격으로 열람하거나 삭제할 수 없습니다.
